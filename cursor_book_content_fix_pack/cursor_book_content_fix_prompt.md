# Cursor task — Leo Kids book content cleanup before launch

## Goal
Fix the learning-book text content before launch. This task is **content cleanup only**. Do **not** work on TTS/audio generation now.

The books must feel like polished enrichment/explanation books for children, not like copied syllabus notes between grades.

## Scope
Work only on the book text files, unless a generated index/book-full file must be regenerated by an existing project script.

Expected area:
- `audio-text/books/**/pages/page-*.txt`
- If these live elsewhere in this repo, locate the equivalent `books/<subject-g*>/pages/page-*.txt` files.

Do not change UI, login, PWA, reports, games, database, routing, or unrelated code.

## Owner requirements
1. The content must be correct, natural, and suitable for children.
2. No copy-paste feeling from one grade/book to another.
3. No duplicate examples between books unless there is a clear educational reason — and even then the wording/example must be adapted.
4. Remove syllabus/meta wording such as:
   - `בכיתה ב׳ נלמד...`
   - `בכיתה א׳ לא לומדים...`
   - `ברמת כיתה ב׳`
   - `זה לכיתה ד׳`
   - `ממה שלמדנו בכיתה...`
   - `מניחים שעברתם על יסודות כיתה...`
5. This is a learning/enrichment book. Use natural wording like:
   - `כאן נתרגל...`
   - `נכיר דרך פשוטה...`
   - `נחזק את הרעיון...`
   - `בדוגמה הזאת...`
   - `בתרגול הזה...`
6. If “כיתה” is used as a real place in a sentence/story, it can stay. Example: `נכנסנו לכיתה`, `המורה אמרה לכיתה`. The ban is on grade/syllabus comments.

## Do not make these mistakes
- Do not rewrite everything freely.
- Do not make the Hebrew sound like machine translation.
- Do not insert English labels into Hebrew books.
- Do not remove the pedagogic structure of the books.
- Do not change page numbering or delete pages.
- Do not replace content with vague filler.
- Do not add clinical/diagnostic/psychological wording.

## Required systemic fixes

### A. Remove all `שאלה מסעיף 5`
There are many pages, especially Hebrew. This is not natural book wording.

Replace every occurrence of:
```text
שאלה מסעיף 5:
```
with:
```text
בואו נבדוק יחד:
```

Keep the actual question text after it. Do not leave “סעיף 5” anywhere.

### B. Remove adjacent duplicate lines
If a page has the same non-empty line twice in a row, keep only one.
Examples:
```text
blue
blue
```
should become:
```text
blue
```

This is a content/professionalism issue, not only audio.

### C. Remove grade/syllabus/meta wording
Use the attached CSV list as the exact review list: `cursor_content_fix_findings.csv`, category `Grade/meta wording`.

Rewrite only the meta/syllabus meaning. Examples:

- Replace `בכיתה א׳ נשתמש...` with `כאן נשתמש...`
- Replace `בכיתה ב׳ לא נלמד שארית...` with `כאן מתרגלים חלוקה שווה פשוטה, בלי שארית.`
- Replace `זה לכיתה ד׳` with `כאן נתמקד רק ברעיון הנוכחי.`
- Replace `ברמת כיתה ב׳` with `בתרגול הזה` or remove entirely.
- Replace `מניחים שעברתם על יסודות כיתה א׳` with `נמשיך מהיסודות שכבר הכרנו.`

If “כיתה” is a physical place in the sentence/story, keep it.

### D. Fix cross-book duplicates and near-duplicates
Use the attached CSV categories:
- `Cross-book duplicate`
- `Near duplicate lesson`

Do not simply delete these pages. Rewrite/adapt the higher-grade page so each book has its own example and level.

Minimum expectation:
- same topic may repeat across grades only as spiral learning;
- examples must not be identical;
- numbers/story/context should change;
- the higher grade must add a slightly deeper explanation or more advanced application.

### E. Keep each lesson self-contained
Every page should make sense on its own. Avoid:
- `כמו שראינו קודם` without context
- `השאלה הקודמת` if the question is not present
- `סעיף 5`
- references to a classroom syllabus
