## 2. הסבר

**זוגות ל-10:**
**1 + 9**, **2 + 8**, **3 + 7**, **4 + 6**, **5 + 5**

**חשוב:** הסדר **לא** משנה!
**7 + 3 = 10** וגם **3 + 7 = 10**

**איך זה עוזר בחיבור?**
ב-**8 + 5** אפשר לחשוב: **8** צריך **2** כדי להגיע ל-**10**, ואז נשאר **3**.
**8 + 5 = 8 + 2 + 3 = 10 + 3 = 13**
