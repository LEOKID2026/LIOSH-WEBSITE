## 1. מה לומדים?

היום נחזור על מספרים **זוגיים** ו**אי-זוגיים**.
גם מספרים גדולים — כמו **24** או **35** — אפשר לבדוק **באותה דרך**: סידור **בזוגות**.

---

## 2. הסבר

**מספר זוגי** — אפשר לסדר ב**זוגות**, ולכל אחד יש **שותף**.
**אף אחד** לא נשאר לבד.

**מספר אי-זוגי** — מסדרים בזוגות, ו**נשאר אחד בלי שותף**.

**שתי דרכים לבדוק:**
1. **סידור בזוגות** — הדרך הכי ברורה
2. **הספרה האחרונה** — 0, 2, 4, 6, 8 → **זוגי** | 1, 3, 5, 7, 9 → **אי-זוגי**

---

## 3. דוגמה

**24 — זוגי:**

```
★ ★    ★ ★    ★ ★    … (12 זוגות)
```

לכל כוכב יש **שותף** → **24** **זוגי**.

**35 — אי-זוגי:**

```
★ ★    ★ ★    ★ ★    … ★
```

נשאר **כוכב אחד** לבד → **35** **אי-זוגי**.

**טיפ:** ב-**35** הספרה האחרונה היא **5** → **אי-זוגי**.

---

## 4. בואו נפתור

**שאלה:** האם **24** זוגי או אי-זוגי?

**שלב 1:** מסדרים **24** בזוגות — לכל אחד יש **שותף**.

**שלב 2:** **לא** נשאר אף אחד לבד.

**שלב 3:** הספרה האחרונה ב-**24** היא **4** → **זוגי**.

**תשובה:** **24** הוא **זוגי**.

## 6. שימו לב!

**קל לטעות:** לחשוב ש-**35** **זוגי** כי הוא "גדול".

❌ **35** **זוגי** — **לא נכון!** כש**מסדרים בזוגות, נשאר אחד בלי שותף**.

✓ **35** **אי-זוגי** — הספרה האחרונה **5** גם מסמנת **אי-זוגי**.

**זכרו:** גודל המספר **לא** קובע. קודם **סדרו בזוגות**, ואז בדקו.
