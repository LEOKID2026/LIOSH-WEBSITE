## 1. מה לומדים?

היום נלמד למצוא **שכנים** גם כש**עוברים עשרה** — למשל מ-**199** ל-**200**.
**שכן** = תמיד **±1**, גם כש**העשרות** או **המאות** משתנות.

---

## 2. הסבר

**שכן לפני** = המספר **פחות 1**.
**שכן אחרי** = המספר **פלוס 1**.

**מעבר עשרה — דוגמה חשובה:**
- **199** → שכן אחרי = **200** (לא **190**!)
- **200** → שכן לפני = **199** (לא **100**!)

**248:**
- שלפני: **247**
- אחרי: **249**

**הכלל:** **+1** או **−1** — **לא** קפיצה של **10**.

---

## 3. דוגמה

**ציר מספרים — השכנים של 248:**

```
… 246 — 247 — [248] — 249 — 250 …
              ↑       ↑
           שכן לפני  שכן אחרי
```

**248 − 1 = 247**  
**248 + 1 = 249**

---

## 4. בואו נפתור

**שאלה:** מה השכנים של **248**?

**שלב 1:** שלפני → **248 − 1 = 247**

**שלב 2:** אחרי → **248 + 1 = 249**

**תשובה:** **247** ו-**249**

## 6. שימו לב!

**קל לטעות:** לחשוב שאחרי **199** בא **190** או **299**.

❌ השכנים של **199** הם **189** ו-**299** — **לא נכון!**

✓ השכנים של **199** הם **198** ו-**200** — **מעבר עשרה**, אבל עדיין **±1**.

**זכרו:** אחרי **199** בא **200** — **לא** 300.
