## 1. מה לומדים?

היום נפתור **משוואת חיסור** עם **מספר חסר** — למשל **__ − 45 = 120**.
צריך למצוא את **המספר הגדול** — ממנו מחסרים.

---

## 2. הסבר

**__ − 45 = 120**

שואלים: ממספר כלשהו חיסרו 45 וקיבלו 120 — **מה המספר?**

**120 + 45 = 165**

**165 − 45 = 120** ✓

**כלל:** מספר חסר **לפני** המינוס = **חיבור** של התוצאה והמחוסר.

---

## 3. דוגמה

**__ − 72 = 208**

208 + 72 = **280**

**280 − 72 = 208**

## 4. בואו נפתור

**שאלה:** __ − 38 = 142 — מה המספר החסר?

**שלב 1:** 142 + 38 = **180**.

**שלב 2:** 180 − 38 = 142 ✓

**תשובה:** המספר החסר הוא **180**.

## 5. נסו בעצמכם

**__ − 45 = 120** — מה המספר החסר?

*(רמז: 120 + 45.)*

## 6. שימו לב!

**קל לטעות:** ב-**__ − 45 = 120** לחשב **120 − 45 = 75**.

❌ __ = **75** — 75 − 45 = **30**, לא 120!

✓ __ = **165** — 165 − 45 = 120 (120 + 45 = 165).

**זכרו:** מספר חסר **לפני** המינוס → **חברו** את שני המספרים האחרים!
