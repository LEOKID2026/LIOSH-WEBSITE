## 1. מה לומדים?

היום נלמד לחבר **שלושה מספרים** — **בזה אחר זה** או בקבוצות נוחות.
למשל: 350 + 120 + 80.

---

## 2. הסבר

**דרכים לחבר שלושה מספרים:**

1. **בזה אחר זה:** (350 + 120) + 80
2. **זוג נוח קודם:** 350 + (120 + 80) — כש-120 + 80 = 200
3. **עיגול:** 398 + 102 + 50 → (398 + 102) + 50 = 500 + 50

**חשוב:** לחבר **את כל שלושת** המספרים — לא לעצור אחרי שניים!

**350 + 120 + 80:**
- 350 + 120 = 470
- 470 + 80 = **550**

---

## 3. דוגמה

**1,200 + 300 + 500**

1,200 + 500 = **1,700** (שני המספרים הגדולים קודם)  
1,700 + 300 = **2,000**

**1,200 + 300 + 500 = 2,000**

---

## 4. בואו נפתור

**שאלה:** חשבו: 680 + 120 + 200 = ?

**שלב 1:** 680 + 120 = **800** (זוג נוח — מסתיים ב-0).

**שלב 2:** 800 + 200 = **1,000**.

**תשובה:** 680 + 120 + 200 = **1,000**

---

## 5. נסו בעצמכם

חשבו: **450 + 120 + 80** = ?

*(רמז: 120 + 80 = 200. ואז + 450.)*

---

## 6. שימו לב!

**קל לטעות:** ב-**450 + 120 + 80** לעצור אחרי **450 + 120 = 570** ולא להוסיף את **80**.

❌ 450 + 120 + 80 = **570** — **שכחו** את 80!

✓ 570 + 80 = **650**.

**זכרו:** יש **שלושה** מספרים — וודאו ש**כולם** בתשובה.
