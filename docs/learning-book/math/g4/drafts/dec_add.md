## 1. מה לומדים?

היום נלמד **לחבר מספרים עשרוניים** עם **שתי ספרות** אחרי הנקודה — למשל **3.45 + 2.30**.
**חשוב:** מיישרים **נקודות** — מאיות מתחת למאיות, עשיריות מתחת לעשיריות, שלם מתחת לשלם.

---

## 2. הסבר

**3.45 + 2.30**

3.45  
+ 2.30  
——

- **מאיות:** 5 + 0 = **5**
- **עשיריות:** 4 + 3 = **7**
- **שלם:** 3 + 2 = **5**

**3.45 + 2.30 = 5.75**

**כלל:** מחברים **עמודה אחר עמודה** — כמו בחיבור שלם, רק עם **נקודה** באותו מקום.

---

## 3. דוגמה

**2.18 + 4.06**

מאיות: 8 + 6 = 14 → כותבים **4**, נושאים **1** לעשיריות  
עשיריות: 1 + 0 + 1 = **2**  
שלם: 2 + 4 = **6**

**2.18 + 4.06 = 6.24**

## 4. בואו נפתור

**שאלה:** חשבו: 1.35 + 3.42 = ?

**שלב 1:** מאיות: 5 + 2 = 7.

**שלב 2:** עשיריות: 3 + 4 = 7.

**שלב 3:** שלם: 1 + 3 = 4.

**תשובה:** 1.35 + 3.42 = **4.77**

## 6. שימו לב!

**קל לטעות:** ב-**3.45 + 2.30** לחבר **345 + 230 = 575** **בלי** נקודה — או לשכוח **מאיות**.

❌ 3.45 + 2.30 = **575** — חסרה **נקודה**!

❌ 3.45 + 2.30 = **5.7** — חיברו רק **עשיריות**, שכחו **מאיות** (5 + 0)!

✓ מאיות 5, עשיריות 7, שלם 5 → **5.75**.

**זכרו:** **שתי ספרות** אחרי הנקודה — והנקודה **באותו מקום** בתשובה.
