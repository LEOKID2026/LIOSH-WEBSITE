## 1. מה לומדים?

היום נמצא **שכנים** במספרים **גדולים** — עד **10,000**.
**±1** גם כש**עוברים אלף** — למשל **1,999 → 2,000 → 2,001**.

---

## 2. הסבר

**שכן שלפני** = **−1**
**שכן אחרי** = **+1**

**2,450:**
- שלפני: **2,449**
- אחרי: **2,451**

**מעבר אלף:**
- **1,999** → אחרי = **2,000**
- **2,000** → שלפני = **1,999**

**ערך המקום:** כש**עוברים אלף**, **כל** הספרות יכולות להשתנות — אבל **הקפיצה** עדיין **1**.

---

## 3. דוגמה

**3,628:**

```
3,626 — 3,627 — [3,628] — 3,629 — 3,630
```

**3,628 − 1 = 3,627**  
**3,628 + 1 = 3,629**

**2,999 → 3,000:** שכן אחרי ל-**2,999** = **3,000** — **מעבר אלף**, **+1** בלבד.

---

## 4. בואו נפתור

**שאלה:** מה השכנים של **2,450**?

**שלב 1:** שלפני = **2,450 − 1 = 2,449**

**שלב 2:** אחרי = **2,450 + 1 = 2,451**

**תשובה:** **2,449** ו-**2,451**

## 6. שימו לב!

**קל לטעות:** ב-**2,450** לחשוב שהשכן שלפני הוא **2,440** (**−10**).

❌ שלפני **2,450** = **2,440** — קפיצה של **10**!

✓ שלפני **2,450** = **2,449**. אחרי = **2,451**.

**זכרו:** **מעבר אלף** = עדיין **±1**, לא **±10** או **±100**.
