## 2. הסבר

שכן לפני = מספר קטן ב-1
שכן אחרי = מספר גדול ב-1

45,600:
- שלפני: 45,599
- שאחרי: 45,601

במספרים גדולים צריך לשים לב לעשרות, מאות ואלפים — לא רק לאחדות.

## 4. בואו נפתור

שלב 2: בדיקה: 45,599 + 1 = 45,600 ✓

## 5. נסו בעצמכם

מה המספר שלפני 45,600? ומה המספר שאחרי 45,600?

## 6. שימו לב!

קל לטעות: ב-45,600 לענות 45,500 כשכן שלפני — שכחו את האחדות.

❌ שלפני 45,600 → 45,500 — ירדו 100, לא 1!

✓ שלפני 45,600 = 45,599; אחרי = 45,601.

זכרו: שכן = שינוי של 1 בלבד, גם במספרים גדולים.
