## 1. מה לומדים?

היום נראה איך **זוגות ל-100** עוזרים גם ב**אומדן** — כשלא צריך תשובה **מדויקת**, אלא **קרובה**.
הזוג **37 + 63 = 100** שימושי גם כש**מעגלים** מספרים.

---

## 2. הסבר

**37 + 63 = 100** — זוג שכדאי **לזכור**.

**קשר לאומדן:**
- **37** קרוב ל-**40** (עיגול לעשרה הקרוב)
- **63** קרוב ל-**60**
- **40 + 60 = 100** — **אומדן** מהיר!

**אומדן חיבור:** **37 + 58 ≈ ?**
- **37 ≈ 40**, **58 ≈ 60**
- **40 + 60 = 100** — התשובה האמיתית (**95**) **קרובה ל-100** ✓

**משלימים ל-100** = בסיס ל**חשיבה על "כמה חסר ל-100"** — גם באומדן.

---

## 3. דוגמה

**אומדן:** כמה בערך **52 + 49**?

**52** קרוב ל-**50**. **49** קרוב ל-**50**.
**50 + 50 = 100** — **אומדן:** בערך **100**.

**בדיקה:** **52 + 49 = 101** — קרוב מאוד! ✓

**52 + 48 = 100** בדיוק — **52** ו-**48** הם **זוג ל-100**.

---

## 4. בואו נפתור

**שאלה:** **37 + ? = 100** — מה המספר החסר?

**שלב 1:** **100 − 37 = 63**.

**שלב 2:** בדיקה: **30 + 70 = 100**, ו-**7 + 3 = 10** → **100** ✓

**שלב 3 (אומדן):** **37 ≈ 40**, **63 ≈ 60** → **40 + 60 = 100** — **הזוג מתאים**.

**תשובה:** המספר החסר הוא **63**.

---

## 6. שימו לב!

**קל לטעות:** ב-**37 + ? = 100** לענות **73** (הפכנו ספרות).

❌ **37 + 73 = 110** — **יותר מ-100**!

✓ **37 + 63 = 100** — תמיד **בודקים** שהסכום **בדיוק 100**.

**זכרו:** **אומדן** עוזר לבדוק — אם יצא **110**, משהו **לא** מתאים.
