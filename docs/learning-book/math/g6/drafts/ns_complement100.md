## 1. מה לומדים?

היום נחזק **זוגות ל-100** — ונראה **קשר** ל**עשרוניים** ו**אחוזים**.
כששני חלקים **יחד** נותנים **100%** (או **1 שלם**) — זה **אותו רעיון** כמו **63 + 37 = 100**.

---

## 2. הסבר

**63 + 37 = 100** — זוג מוכר.

**קשר לעשרוניים:**
- **0.63 + 0.37 = 1.00** (שלם אחד)
- **0.63** = **63** מאיות → **63%**
- **0.37** = **37** מאיות → **37%**
- **63% + 37% = 100%**

**זוגות נוספים:**
- **82 + 18 = 100** → **0.82 + 0.18 = 1.00**
- **45 + 55 = 100** → **45% + 55% = 100%**

**הרעיון:** שני חלקים **משלימים** ל**שלם** — בין אם **100**, **1.00**, או **100%**.

---

## 3. דוגמה

**18 + ? = 100**

**100 − 18 = 82**

**בדיקה:** **18 + 82 = 100** ✓

**קשר:** **18%** + **82%** = **100%**  
**0.18** + **0.82** = **1.00**

## 4. בואו נפתור

**שלב 3 (קשר):** **63%** + **37%** = **100%**.

**תשובה:** המספר החסר הוא **37**.
