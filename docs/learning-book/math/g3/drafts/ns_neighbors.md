## 1. מה לומדים?

היום נמצא **שכנים** של מספר — **±1** — גם כש**עוברים גבול מאה**.
לדוגמה: **399 → 400 → 401** — כל צעד הוא **1** בלבד.

---

## 2. הסבר

**שכן שלפני** = **−1** (צעד **אחורה**).
**שכן אחרי** = **+1** (צעד **קדימה**).

**350:**
- שלפני: **349**
- אחרי: **351**

**מעבר מאה:**
- **499** → אחרי = **500**
- **500** → שלפני = **499**

**999** → אחרי = **1,000** (עוברים **מאה** חדשה!)

---

## 3. דוגמה

**628 על ציר המספרים:**

```
626 — 627 — [628] — 629 — 630
```

**628 − 1 = 627**  
**628 + 1 = 629**

**399 → 400:** שכן אחרי ל-**399** = **400** — **גבול מאה**, אבל עדיין **+1**.

---

## 4. בואו נפתור

**שאלה:** מה **השכן שלפני** **415**? מה **השכן אחרי** **415**?

**שלב 1:** שלפני = **415 − 1 = 414**

**שלב 2:** אחרי = **415 + 1 = 416**

**תשובה:** **414** ו-**416**

---

## 5. נסו בעצמכם

מה השכן **שלפני** ו**אחרי** המספר **350**?

*(רמז: **350 − 1** ו-**350 + 1** — שימו לב ל**עשרות**.)*

## 6. שימו לב!

**קל לטעות:** ב-**350** לחשוב שהשכן שלפני הוא **340** (**−10**).

❌ שלפני **350** = **340** — קפיצה של **10**, **לא** שכן!

✓ שלפני **350** = **349**. אחרי **350** = **351**.

**זכרו:** **גבול מאה** לא משנה — שכן = **±1** בלבד.
