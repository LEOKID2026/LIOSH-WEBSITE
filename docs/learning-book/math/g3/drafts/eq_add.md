## 1. מה לומדים?

צריך למצוא מה חסר כדי שהשוויון יהיה **נכון**.

## 2. הסבר

**45 + __ = 72**

שואלים: מה צריך **להוסיף** ל-45 כדי להגיע ל-72?

**72 − 45 = 27**

**45 + 27 = 72** ✓

**או:** חושבים — 45 + 20 = 65, עוד 7 → **27**.

**המספר החסר** הוא **27** — לא 72!

## 4. בואו נפתור

**שלב 2:** בדיקה: 52 + 28 = 80 ✓

**תשובה:** המספר החסר הוא **28**.

## 6. שימו לב!

**קל לטעות:** ב-**45 + __ = 72** לכתוב **72** במקום הריק.

❌ 45 + **72** = 72 — 45 + 72 = **117**, לא 72!

✓ 45 + **27** = 72 — המספר החסר הוא **27**.

**זכרו:** __ = מה **חסר**, לא התוצאה שכבר כתובה אחרי =.
