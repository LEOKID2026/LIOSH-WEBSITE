## 1. מה לומדים?

היום נלמד **לחבר מספרים עשרוניים** — עם **נקודה** (למשל 2.3 + 1.4).
**חשוב:** ליישר את **הנקודות** — חלק שלם מתחת לשלם, עשיריות מתחת לעשיריות.

---

## 2. הסבר

**2.3 + 1.4**

- **2** + **1** = 3 (שלם)
- **0.3** + **0.4** = **0.7** (אחרי הנקודה)

**2.3 + 1.4 = 3.7**

**כלל:** מחברים **כאילו אין נקודה**, ואז **שמים נקודה** באותו מקום.

---

## 3. דוגמה

**4.2 + 3.5**

שלם: 4 + 3 = 7  
עשיריות: 2 + 5 = 7  

**4.2 + 3.5 = 7.7**

---

## 4. בואו נפתור

**שאלה:** חשבו: 1.6 + 2.2 = ?

**שלב 1:** שלם: 1 + 2 = 3.

**שלב 2:** עשיריות: 6 + 2 = 8 → 0.8.

**תשובה:** 1.6 + 2.2 = **3.8**

---

## 5. נסו בעצמכם

חשבו: **2.3 + 1.4** = ?

*(רמז: 2+1 ו-0.3+0.4.)*

---

## 6. שימו לב!

**קל לטעות:** ב-**2.3 + 1.4** לחבר **23 + 14 = 37** **בלי** נקודה.

❌ 2.3 + 1.4 = **37** — שכחו את **הנקודה**!

✓ 2.3 + 1.4 = **3.7** — הנקודה **מתחת לנקודה**.

**זכרו:** אחרי החיבור — **נקודה** לפני ספרת העשיריות.
