## 2. הסבר

**5.7 − 2.2**

- **5** − **2** = 3
- **0.7** − **0.2** = **0.5**

**5.7 − 2.2 = 3.5**

**בדיקה:** 3.5 + 2.2 = 5.7 ✓

---

## 3. דוגמה

**8.4 − 3.1**

8 − 3 = 5  
0.4 − 0.1 = 0.3  

**8.4 − 3.1 = 5.3**

## 4. בואו נפתור

**שאלה:** חשבו: 6.8 − 2.3 = ?

**שלב 1:** שלם: 6 − 2 = 4.

**שלב 2:** עשיריות: 8 − 3 = 5 → 0.5.

**תשובה:** 6.8 − 2.3 = **4.5**
