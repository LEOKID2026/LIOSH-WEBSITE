## 2. הסבר פשוט

יש **זוגות מיוחדים** שתמיד מגיעים ל-**10**:
**1 + 9**, **2 + 8**, **3 + 7**, **4 + 6**, **5 + 5**

**חשוב:** הסדר **לא** משנה!
**3 + 7 = 10** וגם **7 + 3 = 10**

## 3. דוגמה

**מסגרת עשר — 3 מקומות מלאים, 7 מקומות ריקים:**

```
┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐
│ ●│ ●│ ●│ ○│ ○│ ○│ ○│ ○│ ○│ ○│
└──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘
  3 מקומות מלאים          7 מקומות ריקים
```

**כיתוב:** **3 + 7 = 10**. הזוג של **3** הוא **7**.

**דוגמה עם תפוחים:**
יש לי **6** תפוחים. כמה עוד צריך כדי שיהיו **10**? **4** — כי **6 + 4 = 10**.

## 4. בואו נפתור יחד

**שאלה:** **8 + ? = 10** — מה המספר החסר?

**שלב 1:** במסגרת עשר — ממלאים **8** מקומות

**שלב 2:** נשארו **2** מקומות ריקים

**שלב 3:** הזוג של **8** הוא **2** — כי **8 + 2 = 10**

**תשובה:** **8 + 2 = 10**

## 6. טעות נפוצה — שימו לב!

**קל לטעות:** לחשוב שהמספר שמשלים את **4** ל-**10** הוא **10**.

❌ **4 + 10 = 14** — **לא נכון**, כי **4 + 10** גדול מ-**10**.

✓ **4 + 6 = 10** — הזוג של **4** הוא **6**.

**זכרו:** שני המספרים **יחד** צריכים להיות **בדיוק 10**.
