## 2. הסבר פשוט

**3 × 2** = שלוש **קבוצות** של **2**
= 2 + 2 + 2 = **6**

**×** אומר "קבוצות של". אפשר גם לומר "פעמים".
**3 × 2 = 6** — שלוש פעמים שתיים.

**בכיתה א׳ נשתמש בכפל קטן: קבוצות עד 5, והתוצאה עד 20.**

---

## 3. דוגמה

**3 × 2 — שלוש קבוצות של 2 כוכבים:**

```
★ ★    ★ ★    ★ ★
קבוצה 1  קבוצה 2  קבוצה 3
```

**חיבור חוזר:** 2 + 2 + 2 = **6**
**כפל:** 3 × 2 = **6**

**דוגמה עם מדבקות:**
4 קבוצות, בכל קבוצה 3 מדבקות → 3 + 3 + 3 + 3 = **12**
→ 4 × 3 = **12**

## 4. בואו נפתור יחד

**שאלה:** 2 × 4 = ?

**שלב 1:** 2 **קבוצות** של **4**

**שלב 2:** חיבור חוזר: 4 + 4 = **8**

**תשובה:** 2 × 4 = **8**

## 6. טעות נפוצה — שימו לב!

**קל לטעות:** לחבר רק שתי קבוצות במקום את כל הקבוצות.

❌ 3 × 3 = 3 + 3 = **6** — חיברנו רק **שתי** קבוצות.

✓ 3 × 3 = 3 + 3 + 3 = **9** — שלוש קבוצות של 3.

**זכרו:** × זה **קבוצות שוות**, וצריך לחבר את כל הקבוצות.
