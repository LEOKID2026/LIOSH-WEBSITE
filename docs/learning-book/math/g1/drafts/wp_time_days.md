## 1. מה אנחנו לומדים?

היום נלמד לענות: **כמה ימים עוברים מיום אחד עד יום אחר** — או **כמה ימים לפני / אחרי** יום מסוים.
סופרים **צעדים** על שורת ימי השבוע, כמו קפיצות על ציר המספרים.

---

## 2. הסבר פשוט

שורת ימי השבוע:

```
[ראשון] [שני] [שלישי] [רביעי] [חמישי] [שישי] [שבת]
```

**כמה ימים עד** יום מסוים? → סופרים **קפיצות קדימה** מיום ליום.

**כמה ימים לפני** יום מסוים? → סופרים **אחורה**.

לפני שעונים:
1. **מה יודעים?** — מאיזה יום מתחילים
2. **מה מבקשים?** — כמה **ימים** (או איזה יום, אם שואלים "מתי")
3. **מה עושים?** — **סופרים צעדים** על שורת הימים

---

## 3. דוגמה

**כמה ימים מיום ראשון עד יום רביעי?**

```
[●ראשון] → [שני] → [שלישי] → [●רביעי]
           ①         ②         ③
```

**3 צעדים** → **3 ימים**.

**2 ימים לפני יום שישי — איזה יום?**

```
[●רביעי] ← [חמישי] ← [●שישי]
   ②          ①
```

**2 ימים לפני שישי** → יום **רביעי**.

---

## 4. בואו נפתור יחד

**שאלה:** אם היום יום ראשון, כמה ימים יעברו עד יום רביעי?

**שלב 1 — מה יודעים?**
**מתחילים:** יום ראשון
**מגיעים ל:** יום רביעי

**שלב 2 — מה מבקשים?**
**כמה ימים** יעברו — צריך **לספור צעדים קדימה**.

**שלב 3 — סופרים:**
ראשון → (1) שני → (2) שלישי → (3) **רביעי**

**תשובה:** יעברו **3 ימים**.

---

## 5. נסו בעצמכם

היום יום שישי. **לפני 2 ימים** — איזה יום היה?

*(רמז: ספרו 2 צעדים **אחורה** משישי)*

---

## 6. טעות נפוצה — שימו לב!

**קל לטעות בשתי דרכים:** לספור את **יום ההתחלה** כצעד ראשון — או **לעצור לפני** יום היעד.

❌ מראשון עד רביעי → "ראשון, שני, שלישי" — ספרנו את **ראשון** כצעד, ו**עצרנו לפני רביעי** → רק **2** ימים!

✓ מראשון עד רביעי → **אחרי** ראשון, כל **קפיצה** עד רביעי: (1) שני → (2) שלישי → (3) **רביעי** → **3 ימים**

**זכרו:** אחרי היום שבו מתחילים — סופרים **קפיצה אחר קפיצה** עד יום היעד.
