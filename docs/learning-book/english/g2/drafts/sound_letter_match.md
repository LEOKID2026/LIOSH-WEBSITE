## 1. מה לומדים?

היום נחזק **חיבור** בין צליל לאות — בשני הכיוונים.
שומעים צליל mmm — בוחרים M. רואים S — אומרים צליל sss.

---

## 2. הסבר

צליל → אות:

צליל mmm → **M**  
צליל sss → **S**  
צליל כמו ב-cat → **C**  

אות → צליל:

**B** → bbb  
**T** → ttt  

---

## 3. דוגמה

שומעים mmm — **M**.

רואים **F** — fff.

---

## 4. בואו נפתור

שאלה: איזו אות — צליל כמו ב-cat?

שלב 1: cat מתחיל ב-c.

שלב 2: **C**.

תשובה: C
