## 2. הסבר

קוראים מילה מימין לשמאל.
בַּת — בּ + ת + תנועה = בַּת.

קודם כל אות, אחר כך מחברים לצליל, ואז קוראים את כל המילה.

---

## 3. דוגמה

בּ — ב
ת — ת
יחד: בַּת

קָרָא — קראתי את המילה בַּת.

## 4. בואו נפתור

שאלה: איך קוראים בַּ + ת?

שלב 1: בּ — ב.

שלב 2: ת — ת.

שלב 3: מחברים — בַּת.

תשובה: בַּת.

## 6. שימו לב!

קל לטעות: לקרוא מהר בלי לחבר את האותיות.

❌ בַּת — ב, ת בנפרד — לא! צריך לקרוא בַּת.

✓ קָרָא — בַּת, מילה שלמה.
