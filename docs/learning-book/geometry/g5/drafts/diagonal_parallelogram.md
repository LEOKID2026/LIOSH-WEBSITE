## 1. מה לומדים?

היום נלמד **אלכסון במקבילית**.

האלכסון מחלק את המקבילית ל**שני משולשים** — משתמשים ב**שתי צלעות סמוכות** כניצבים.

---

## 2. הסבר

אם צלעות סמוכות **5 ס״מ** ו-**12 ס״מ**:
אלכסון = √(5² + 12²) = √(25 + 144) = √169 = **13 ס״מ**

---

## 3. דוגמה

דוגמה נוספת: 3 ס״מ ו-4 ס״מ → √(9+16) = **5 ס״מ**

## 4. בואו נפתור

**שאלה:** מקבילית — צלעות סמוכות **5 ס״מ** ו-**12 ס״מ**. אלכסון?

**שלב 1:** 25 + 144 = 169.

**שלב 2:** √169 = **13**.

**תשובה:** **13 ס״מ**.

## 5. נסו בעצמכם

## 6. שימו לב!

בצלעות **5 ס״מ** ו-**12 ס״מ** לפעמים מחברים **5+12=17**.

❌ 17 ס״מ — חיבור, לא אלכסון!

✓ **13 ס״מ**.

**זכרו:** √(5² + 12²).
