# בדיקות ידניות — מרכז עזרה

## מקלדת ומיקוד

- [ ] Tab / Shift+Tab מגיעים לכל קישור בעמודי `/help/**`
- [ ] טבעת מיקוד נראית (`focus-visible:ring-amber-300/70`)
- [ ] קישור «דלג לתוכן» מוביל ל־`#help-main`

## כותרות ו־RTL

- [ ] כותרת `h1` אחת בכל עמוד
- [ ] סדר כותרות: h1 → h2 → h3
- [ ] `dir="rtl"` — אין גלילה אופקית ב־390px

## נגישות תמונות

- [ ] לכל תמונה יש `alt` בעברית
- [ ] `<picture>` מציג גרסת mobile / tablet / desktop

## ניגודיות (דגימה)

- [ ] כותרת גרדיאנט וטקסט גוף קריאים בכלי הנגישות של הדפדפן

## דפדפנים

- [ ] Chrome / Firefox / Safari (שולחן עבודה)
- [ ] Safari iOS / Chrome Android (דגימה)

## הערה

אוטומציית axe-core אינה מאושרת בתוכנית — רשימה זו היא נתיב ברירת המחדל.
