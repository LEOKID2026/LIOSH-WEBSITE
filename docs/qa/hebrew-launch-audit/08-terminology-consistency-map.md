# 08 — Terminology Consistency Map

## מפת מונחים בעייתיים

### 1) חשבון / מתמטיקה
- **כל הווריאציות שנמצאו:** `חשבון`, `מתמטיקה`
- **איפה נמצאו:**
  - `lib/learning-client/studentHomeDashboardClient.js` (`חשבון`)
  - `pages/learning/parent-report.js` (`חשבון`)
  - `pages/index.js` (`מתמטיקה`)
  - `utils/parent-report-language/subject-evidence-policy.js` (שתי הווריאציות יחד)
- **וריאציה מומלצת:** `חשבון` למסכי תלמיד/הורה; `מתמטיקה` רק אם הוחלט לשיווק/SEO.
- **האם נדרשת החלטת בעלים:** כן.

### 2) מולדת וגאוגרפיה / מולדת וגיאוגרפיה / מולדת / גיאוגרפיה
- **כל הווריאציות שנמצאו:** `מולדת וגאוגרפיה`, `מולדת וגיאוגרפיה`, `מולדת / גיאוגרפיה`, `מולדת`, `גאוגרפיה`
- **איפה נמצאו:**
  - `pages/learning/moledet-geography-master.js`
  - `pages/learning/index.js`
  - `utils/dev-student-simulator/ui-display-labels.js`
  - `lib/learning-book/learning-book-catalog-meta.js`
- **וריאציה מומלצת:** `מולדת וגאוגרפיה` (אם זו בחירת האיות המאושרת) + נגזרות עקביות ללא סלאש.
- **האם נדרשת החלטת בעלים:** כן.

### 3) דשבורד / לוח בקרה
- **כל הווריאציות שנמצאו:** `דשבורד הורים`, `דשבורד`, `לוח בקרה`, `לוח בקרת בית הספר`
- **איפה נמצאו:**
  - `pages/parent/dashboard.js`
  - `pages/learning/parent-report.js`
  - `pages/learning/parent-report-detailed.js`
  - `lib/school-portal/school-ui.he.js`
- **וריאציה מומלצת:** לבחור תבנית אחידה לפי שפת המוצר (מומלץ `לוח בקרה` אם שואפים לעברית מלאה).
- **האם נדרשת החלטת בעלים:** כן.

### 4) דוח / דו״ח
- **כל הווריאציות שנמצאו:** `דוח` (דומיננטי מאוד), כמעט ללא `דו״ח`.
- **איפה נמצאו:**
  - `pages/learning/parent-report.js`
  - `pages/learning/parent-report-detailed.js`
  - `lib/parent-report-server-truth.js`
  - `utils/parent-copilot/*`
- **וריאציה מומלצת:** להשאיר `דוח` אם זו החלטת סגנון רשמית.
- **האם נדרשת החלטת בעלים:** לא (אלא אם נדרשת התאמה לשפה תקנית-אקדמית מחמירה).

### 5) שאלות / תרגילים
- **כל הווריאציות שנמצאו:** `שאלות`, `תרגול`, `תרגילים`
- **איפה נמצאו:**
  - `pages/student/home.js`
  - `pages/learning/*-master.js`
  - `utils/parent-report-language/subject-evidence-policy.js`
- **וריאציה מומלצת:** `שאלות` למדד כמותי, `תרגול/תרגילים` לפעילות; להימנע מהחלפה אקראית באותו רכיב.
- **האם נדרשת החלטת בעלים:** כן.

### 6) התחברות / כניסה
- **כל הווריאציות שנמצאו:** `התחברות`, `כניסה`, `התחברו`
- **איפה נמצאו:**
  - `pages/parent/login.js`
  - `pages/student/login.js`
  - `pages/student/home.js`
  - `lib/platform-ui/hebrew-display-labels.js`
- **וריאציה מומלצת:** `כניסה` לפעולה על כפתור/טאב, `התחברות` כהסבר מצב/שגיאה.
- **האם נדרשת החלטת בעלים:** לא (כל עוד נשמר כלל אחיד).

### 7) ילד / תלמיד
- **כל הווריאציות שנמצאו:** `ילד/ה`, `ילדים`, `תלמיד`, `תלמידים`
- **איפה נמצאו:**
  - `pages/parent/*`
  - `components/teacher-portal/*`
  - `data/help-center/*`
  - `data/hebrew-questions/*`
- **וריאציה מומלצת:** במסכי הורה/בית — `ילד/ה`; במסכי מורה/כיתה — `תלמיד/ה`.
- **האם נדרשת החלטת בעלים:** כן (גבולות קהל יעד בין פורטלים).

### 8) הורה / משפחה
- **כל הווריאציות שנמצאו:** `הורה/הורים`, `משפחה`
- **איפה נמצאו:**
  - `pages/parent/*`
  - `utils/parent-copilot/*`
  - `data/moledet-geography-curriculum.js`
- **וריאציה מומלצת:** `הורה/הורים` בטקסטי מערכת; `משפחה` רק בקונטקסט תוכן לימודי.
- **האם נדרשת החלטת בעלים:** כן.

### 9) פעילות אישית / פעילות מהורה / פעילות מהמורה
- **כל הווריאציות שנמצאו:** `פעילות אישית`, `פעילות הורה`, `פעילות מהמורה` (נוכחות חלקית/הקשרית)
- **איפה נמצאו:**
  - `lib/classroom-activities/student-activity-scope-labels.client.js`
  - `components/teacher-portal/TeacherStudentIndividualActivitiesPanel.jsx`
  - `lib/learning-client/studentHomeDashboardClient.js`
- **וריאציה מומלצת:** `פעילות אישית` כברירת מחדל גלויה, עם תיוג מקור רק כשנדרש.
- **האם נדרשת החלטת בעלים:** כן.

## החלטות בעלים מומלצות להעברה
- אחידות איות: `גאוגרפיה` מול `גיאוגרפיה`.
- אחידות מוצרית: `דשבורד` מול `לוח בקרה`.
- מינוח מקצוע: `חשבון` מול `מתמטיקה`.
- מדיניות חשיפה: שימוש/אי-שימוש בתווי Bidi נסתרים (`\u200F`, `\u2066`, `\u2069`).
